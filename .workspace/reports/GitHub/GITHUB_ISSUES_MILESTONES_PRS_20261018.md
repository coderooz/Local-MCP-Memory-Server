## 7. Methodology & Caveats

- **Retrieval:** `gh` CLI against the GitHub REST API — `issue list --state all`,
  `pr list --state all`, `/repos/{repo}/milestones`, `/repos/{repo}/labels`, `/repos/{repo}`.
- **Encoding:** responses were read as raw bytes via Node `child_process` and written as
  UTF-8. An earlier PowerShell-piped attempt corrupted em-dashes into mojibake and was
  discarded; all figures here were re-fetched cleanly and verified.
- **Verification:** issue + open-PR counts were cross-checked against the repository-level
  `open_issues_count` field and reconcile exactly.
- **Limits:** only the first 500 issues/PRs are requested; the repo is far below that, so the
  data is complete. Comment *bodies* are not reproduced here — only counts.
- **Scope:** this is a read-only snapshot. Milestone and issue counts reflect state as of
  2026-10-18 and will drift as the tracker changes.
